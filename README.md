# Data Centre Management (DCM) 

## 📘 Overview

This repository is designed for **Data Centre Management (DCM)** students and learners focusing on **Amazon Web Services (AWS)**.

It contains:

- Step-by-step AWS implementation guides
- Core exam commands and reminders
- A full practical mock exam
- Monitoring and alerting setup (CloudWatch + SNS)
- A final revision cheat sheet

The content is aligned with the official course materials and practical exam structure.
